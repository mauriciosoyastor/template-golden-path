# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a Vulnerability

Reporta vulnerabilidades por **GitHub Private Vulnerability Reporting** o email al owner del repo. No abras un issue público con detalles del exploit.

Responderemos en 72h y coordinaremos fix + disclosure.

Gracias por hacer el Golden Path más seguro.
