# Code of Conduct

Adoptamos el [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Compromiso

Nos comprometemos a hacer de la participación una experiencia libre de acoso para todos.

## Estándares

Ejemplos de comportamiento que contribuye a un entorno positivo: empatía, respeto, feedback constructivo, foco en lo mejor para la comunidad.

## Aplicación

Reporta incidentes al owner del repo. Se revisarán con confidencialidad y se tomarán acciones correctivas justas.
